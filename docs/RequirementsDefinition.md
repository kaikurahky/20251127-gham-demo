# スペースインベーダー - 要件定義書

## 概要
80年代のアーケードゲーム「スペースインベーダー」のクローンゲーム。
ブラウザ上で動作する HTML5/JavaScript 実装。

## 登場オブジェクト

### 敵（インベーダー）
- 縦5段 × 横11列の隊列が初期状態
- 画面上部から左右移動しつつ降下
- 段ごとに異なる色と得点（上段ほど高得点）
  - 1段目（赤）: 50点
  - 2段目（黄）: 40点
  - 3段目（緑）: 30点
  - 4段目（青）: 20点
  - 5段目（紫）: 10点

### バリア
- 画面に4つ配置
- インベーダーや自機の弾が当たると削れる
- 完全に破壊されると消滅

### 自機（砲台）
- プレイヤーが操作
- 左右移動と弾の発射が可能
- 初期残機は3

### UFO
- 一定時間経過後（15秒）に画面上部を端から端へ飛行
- 撃ち落とすと300点のボーナス

## ゲームルール

1. プレイヤーは自機を操作してインベーダーを撃ち落とす
2. インベーダーが画面下部に到達するとゲームオーバー
3. 自機は敵の弾に当たると残機が減少
4. 残機がなくなるとゲームオーバー
5. インベーダーを全て撃ち落とすと次のステージへ
6. 自機の弾は1発のみ（前の弾が消滅するまで次を撃てない）
7. インベーダーの数が減るごとに移動速度が指数的に上昇（最大10倍）

## 操作方法

| キー | 操作 |
|------|------|
| ← → | 自機を左右に移動 |
| スペース | 弾を発射 |
| S | ゲーム開始 |
| P | 一時停止/再開 |
| R | リセット |

## UI要素

- ゲーム画面（Canvas）
- スコア表示
- ハイスコア表示
- 残機表示
- ステージ表示
- START/PAUSE/RESETボタン
- ゲームオーバーポップアップ
- 被弾時ポップアップ

## 音声

- インベーダー移動音（4音ループ: 75.9Hz, 66.2Hz, 62.2Hz, 57.7Hz）
- 発射音
- 爆発音（敵撃破時）
- 被弾音（ホワイトノイズ）
- UFO出現音
- ゲームオーバー音

## データ保存

- ハイスコアはブラウザのlocalStorageに保存
